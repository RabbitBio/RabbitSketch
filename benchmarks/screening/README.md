# RabbitSketch2 synthetic-set screening

Six active candidates, exact constructed set truth, measured query-array
bytes, native timing, resumable jobs, Pareto analysis and conservative
pruning review. Current MinHash is FastKMV; there is no duplicate Legacy entry.
OrderMinHash and dedicated sequence-order experiments are excluded from the
suite and selection guide by user decision (2026-09-30). KSSD is also excluded
by user decision (2026-10-01); its completed historical data remain available.
Read [PROTOCOL.md](PROTOCOL.md) before interpreting results.

Code is kept here; downloads, the pinned upstream source, builds, Python
environment and experiment outputs default to
`/home/bigssd/zt/rabbitsketch2_benchmark`. Existing user worktrees are not modified.
The active execution mode uses the existing `examples/main.cpp` CLI with `-t 64`:
one process runs one algorithm/configuration batch, with OpenMP over its sample
list. Batches run sequentially. `patches/main_screening.patch` adds the synthetic
manifest option to a separate source worktree. The original pilot keeps native
algorithms unchanged. The follow-up uses an explicitly versioned SetSketch
correction in another isolated worktree; see [VALIDATION.md](VALIDATION.md).

The current synthesis is generated by `systematic_analysis.py` under
`results/systematic_20261001/`. It recomputes the six-candidate frontiers and
separates original, corrected synthetic, and real-genome measurement runs.

## Build

`8db783ea75f597068b72705272ae207c94194e83` (branch `lib`).
From this repository's root:

```bash

# Create once. The patch is relative to the upstream repository root.

  --detach /home/bigssd/zt/rabbitsketch2_benchmark/source/RabbitSketch-main \
  8db783ea75f597068b72705272ae207c94194e83
git -C /home/bigssd/zt/rabbitsketch2_benchmark/source/RabbitSketch-main apply \
  /home/user_home/tongz/Finish/RabbitSketch/benchmarks/screening/patches/main_screening.patch

  -B /home/bigssd/zt/rabbitsketch2_benchmark/build_main \

  -DRABBITSKETCH_SCREENING_MAIN=ON \
  -DCMAKE_BUILD_TYPE=Release
cmake --build /home/bigssd/zt/rabbitsketch2_benchmark/build_main \
  --target rabbitsketch_pilot synthetic_pilot --parallel 8

python3 -m venv /home/bigssd/zt/rabbitsketch2_benchmark/venv

  -r benchmarks/screening/requirements.txt
```

For exact reproduction, use the recorded commit, not whatever branch HEAD
points to in a future checkout. The runner records source and binary digests
and rejects incompatible resumes. C++17, CMake>=3.16, OpenMP, libdeflate, zlib and Linux are needed;
analysis dependencies are pinned for Python>=3.10. The orchestrator itself uses
only the Python standard library.

Omit `--threads` to use all CPUs in the process affinity mask. The smoke grid is 252 jobs and
3 replicates per point; it verifies the pipeline and **cannot prune algorithms**.
Its KSSD dictionary parameter differs from the formal grid.
Tests independently reconstruct true sets and exercise full-sampling exactness,
input-order invariance, empty samples, infeasible cells, paired seeds, failed
jobs, pruning gates, crossover arithmetic, thread-count equivalence, and batch
resume. Set `SCREENING_BINARY` / `SCREENING_MAIN_BINARY` for nondefault binaries.

The six-candidate grid has 84,000 pairs in 100 batches of 840. The historical
seven-candidate grid (`configs/pilot.json`, including KSSD) has 90,720 pairs in
108 batches. Frozen run snapshots preserve its original defaults. New `run_main.py`
defaults use the six-candidate config and isolated validated source/build.
Batches are grouped by native
configuration and k. Batch order follows the first appearance in the registered
randomized plan; pair order within each batch is also randomized. `--limit`
can restrict a launch to a smaller validation tranche. Completed rows are reused;
`--retry-failed` retries error/timeout rows. A file lock prevents duplicate writers.
Change output directories when changing source, flags, seeds,
configuration, runner or CPU affinity. The executable is linked from the
configured external source; do not pass an unrelated source path to `run_main.py`.

Each run contains `plan.json`, `manifest.json`, one atomic JSON file per job,
and a regenerated `raw.jsonl`. `progress.json` exposes the current main PID,
algorithm, thread count and completed pairs. `batches/` holds native input
manifests, stderr and batch timing/setup records. Analysis emits:

- `configurations.csv`: error, payload, timing, cardinality and frontier flags.
- `algorithm_decisions.csv`: family-scoped evidence status.
- `query_reuse_winners.csv` and `crossovers.csv`: model-based reuse comparisons.
- `pareto_by_regime.pdf` / `example_regime.png`: standalone figures.
- `report.md` and `analysis_manifest.json`: interpretation and provenance.
- `batches.csv`: shared setup, total wall time and completed-pair throughput.

RSS is the shared main process high-water mark, including all concurrent inputs
and allocator retention; payload is the individual pair's A+B query arrays.
Pair build/query times are elapsed times under batch load. KSSD's dictionary is
initialized once before the parallel loop and recorded separately per batch.
These timings must not be mixed with isolated pair timings from `run.py`.
The analyzer rejects mixed execution profiles or thread counts. `run.py` and
the standalone worker remain available for diagnostic equivalence checks.
No raw-set or genomic ANI truth is fabricated.

The completed full run used frozen scripts under `runs/pilot/code_snapshot/` and a
detached supervisor. All 90,720 measurements and the automatic analysis finished
on 2026-10-01 at 00:15:32 Asia/Shanghai, with zero failed measurements. See
`launch.json`, `status.json`, `progress.json` and `run.log` in that directory.
The earlier serial run is preserved separately as
`runs/pilot_serial_20260930T140437Z` (324 completed rows).

## Published benchmark assets

```bash
python3 benchmarks/screening/prepare_sources.py
```

This downloads/audits the 24 MB Mash archive and six pinned Dashing reference
files. It does not download FASTA. See `sources/mash500/audit.json` and
`sources/dashing/snapshot.json`; every downloaded asset has a SHA-256.

The archive observed in this run has 500 genome identifiers, of which 212 carry
an explicit versioned GCF/GCA accession in the filename. Each sketch table has
249,500 rows but only 124,750 unique pair IDs. Every pair has conflicting
Jaccard observations; 124,498 pair IDs also have conflicting ANI observations.
Both observations are preserved in `ani_observations_unresolved.tsv` with
source line numbers. The audit marks the archive as requiring ID reconciliation;
it is **not ready to join as an ANI truth matrix**. The Jaccard columns are
finite-sketch estimates regardless of this ID issue.

Official entry points: [Mash supporting data](https://mash.readthedocs.io/en/latest/data.html)
and [Dashing experiments](https://github.com/langmead-lab/dashing-experiments).
